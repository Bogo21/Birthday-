# Birthday-
This site is a birthday present for friend, the site has a trek logger and a reminder and virtual pet.

## Layout
- `index.html`: the birthday site (landing, five locks, trek tracker, trail notes, Nut)
- `nut/`: Nut, the virtual pet and reminder page, shown inside the main site

To publish: Settings > Pages > Deploy from branch > `main` / root.
Nut uses a simple built-in brain here; his AI replies and cross-device saving only work inside Claude.
